# Recriando Instagram HTML - Curso DIO

Recriação responsiva da interface atual de autenticação do Instagram, desenvolvida com HTML5, CSS3 e JavaScript puro.

## Estrutura

```text
recriando-instagram-html-profissional/
├── assets/
│   ├── icons/
│   │   └── instagram-glyph.svg
│   └── images/
│       └── hero-collage.png
├── css/
│   └── styles.css
├── js/
│   ├── app.js
│   └── ui-deterrence.js
├── index.html
├── README.md
└── SECURITY.md
```

## Execução

O projeto não exige instalação de dependências ou processo de build.

Abra `index.html` diretamente no navegador ou publique a pasta em qualquer hospedagem estática, incluindo GitHub Pages.

## Recursos

- Layout desktop dividido em painel promocional e autenticação.
- Tema escuro.
- Abordagem responsiva para desktop, tablet e celular.
- Formulário com validação local e estados acessíveis.
- Assets locais e Content Security Policy.
- Bloqueio dissuasório de atalhos de DevTools, menu de contexto e arraste de imagens.
- Compatibilidade com `prefers-reduced-motion`.

## Observação

O formulário é exclusivamente demonstrativo. Nenhuma credencial é transmitida, armazenada ou processada por backend.
